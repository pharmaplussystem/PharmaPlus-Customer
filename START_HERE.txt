PHARMAPLUS CUSTOMER PORTAL - FINAL

1. Extract this folder.
2. Open config.js and put the SAME Supabase Project URL and browser-safe Publishable/anon key used by the PharmaPlus management system.
3. In your Supabase SQL Editor, run the latest online-ordering SQL from the management package. This is required for customer_profiles, online_orders, get_online_pharmacies, get_online_catalog and place_online_order.
4. Upload these files to a SEPARATE GitHub repository and enable GitHub Pages.
5. Customers opening the app now see ONLY Log In and Create Account.
6. First-time customers create their own account and select a pharmacy. Returning customers simply log in.

Included/fixed:
- Cancel buttons work on login, signup, checkout and account forms.
- Account button with profile editing.
- Logout button.
- Theme button with light/dark mode saved on device.
- Customer account is never automatically created on opening the app.
- Login retrieves the customer's own profile and pharmacy.
- Customer shop, cart, checkout and order history.
